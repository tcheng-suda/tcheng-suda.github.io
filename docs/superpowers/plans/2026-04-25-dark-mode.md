# Dark Mode Toggle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a light/dark mode toggle to the Jekyll academic site with CSS variables, system preference detection, and localStorage persistence.

**Architecture:** All colors defined as CSS custom properties on `:root` (light) and `[data-theme="dark"]` (dark). A sun/moon icon in the nav bar toggles the `data-theme` attribute on `<html>`. An inline script in `<head>` prevents flash of wrong theme on load.

**Tech Stack:** Sass/SCSS, CSS custom properties, vanilla JavaScript, Font Awesome 4.3.0 (already loaded)

### Task 8: Add Anti-Flash Script and Toggle JavaScript

**Files:**
- Modify: `_includes/head.html`

- [ ] **Step 1: Add anti-flash inline script before `</head>`**

Add this at the end of `_includes/head.html` (before the closing `</head>` tag on line 18):

```html
<script>
  (function() {
    var saved = localStorage.getItem('theme');
    if (saved) {
      document.documentElement.setAttribute('data-theme', saved);
    } else if (window.matchMedia && window.matchMedia('(prefers-color-scheme: dark)').matches) {
      document.documentElement.setAttribute('data-theme', 'dark');
    }
  })();
</script>
```

- [ ] **Step 2: Add toggle logic script also in `head.html`**

Add this right after the anti-flash script:

```html
<script>
  window.addEventListener('DOMContentLoaded', function() {
    var btn = document.getElementById('theme-toggle-btn');
    var icon = document.getElementById('theme-icon');
    function updateIcon(theme) {
      icon.className = theme === 'dark' ? 'fa fa-moon' : 'fa fa-sun';
    }
    // Set initial icon
    var current = document.documentElement.getAttribute('data-theme') || 'light';
    updateIcon(current);
    btn.addEventListener('click', function() {
      var next = current === 'dark' ? 'light' : 'dark';
      document.documentElement.setAttribute('data-theme', next);
      localStorage.setItem('theme', next);
      current = next;
      updateIcon(next);
    });
  });
</script>
```
